**Location:** Remote (US)

A large set of evaluation tasks is being built for the construction and property field. Each task starts from real drawings, documents and site photos, and asks for the same structured deliverable you would produce at work: a correction letter, a review decision, a marked-up set. You author the task and the correct answer, and a second reviewer in your discipline checks it before it ships.

**What you would be building** 

Tasks drawn from real permit review work, including: building plans examiner review, code consultant plan review, third party and private provider plan review, accessibility and ICC A117.1 review, energy code drawing checks, occupancy classification and storefront change of use, zoning site plan review, permit intake completeness screening, as-built versus permit deviation, and specialty occupancy review for healthcare facilities, schools, food service and public pools.

**Who we are looking for** 

You currently hold, or recently held, the seat that reviews permit drawing sets for code compliance: a building department plans examiner, a third party or private provider plan reviewer, or a code consultant. ICC Building Plans Examiner certification (B1, B2 or B3), or current or recent employment doing AHJ or third party plan review. There is no degree requirement for this role. 3 or more years in the seat, US based, working in US model code jurisdictions (IBC, IEBC, IECC, ICC A117.1). 8 or more years is preferred. You can mark up and measure a plan set. Bluebeam Revu or equivalent.

**What makes someone excellent here** 

The hard part is not applying the code, it is knowing exactly what a careless reviewer would miss. Standouts have usually trained junior examiners, written or maintained a comment library or correction template, done QA on other reviewers' work, or worked across several code editions and jurisdictions and can say precisely what changes between them.

**Probably not a fit** 

General contractors and superintendents without plan review responsibility, estimators, CAD drafters, and permit expediters who file applications but do not review them.

Paid hourly at $45 to $60 depending on experience, with a path to grow your rate as the project scales.

You will be engaged as an independent contractor. This is a fully remote role that can be completed on your own schedule. Projects can be extended, shortened, or concluded early depending on needs and performance. Payments are weekly based on services rendered. No H1-B or STEM OPT support is available at this time.
